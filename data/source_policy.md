# Official-source policy

This project is designed to use official institutional sources.

For each university, documents should be downloaded only from:
1. The university's official domain listed in `universities.json`.
2. Official AP/UGC/SCHE government portals when the document is an official notice/regulation for that university.

Do not represent third-party summaries as university policy.

Each indexed document should retain:
- university name
- filename
- official source URL
- page number where available
- retrieval date
