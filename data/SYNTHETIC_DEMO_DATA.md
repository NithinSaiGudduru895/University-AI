# Synthetic Demo Data

This project currently contains synthetic PDFs under `uploads/<university_id>/` so the RAG pipeline can
be demonstrated immediately.

These PDFs are **not official university documents**. They contain fictional academic/admission/exam
details and must not be presented as real university policy.

For a production or portfolio deployment that makes real-world claims, replace the synthetic PDFs with
documents obtained from the corresponding university's official website or authorized source.

The synthetic PDFs are deliberately labeled inside the documents so a reviewer can distinguish demo
data from authoritative sources.
